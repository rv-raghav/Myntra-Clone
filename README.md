Myntra Clone

Overview

A responsive e-commerce web application replicating Myntra’s UI, built using HTML, CSS, and JavaScript. The project includes dynamic product listings, a shopping cart, and interactive UI elements.

Features

Fully responsive design using Flexbox and Grid

Dynamic product listings and filtering

Interactive shopping cart functionality

JavaScript-powered client-side validation and search

Optimized performance and accessibility

Technologies Used

Frontend: HTML, CSS, JavaScript
