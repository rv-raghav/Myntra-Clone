# Myntra Clone

## Overview
A responsive e-commerce web application replicating Myntra’s UI, built using HTML, CSS, and JavaScript. The project includes dynamic product listings, a shopping cart, and interactive UI elements.

## Features
- Fully responsive design using Flexbox and Grid
- Dynamic product listings and filtering
- Interactive shopping cart functionality
- JavaScript-powered client-side validation and search
- Optimized performance and accessibility

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Styling:** CSS Flexbox, CSS Grid, Tailwind CSS (optional)
- **Interactivity:** Vanilla JavaScript

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/myntra-clone.git
   ```
2. Navigate to the project folder:
   ```sh
   cd myntra-clone
   ```
3. Open `index.html` in your browser.

## Usage
- Browse through the product listings.
- Add products to the cart and view the total price.
- Use the search functionality to find specific products.
